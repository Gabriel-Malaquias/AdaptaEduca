<h1>Adapta Educa</h1>
<h2>Descrição</h2>
<p>O Adapta Educa é uma plataforma desenvolvida com o objetivo de realizar a inclusão no ensino de tecnologia a alunos com
deficiência ou com algum grau de dificuldade no seu processo de aprendizagem. Com o uso do site, qualquer docente pode enviar 
seus planejamentos de aula dos mais diversos formatos para serem aprimorados e adaptados para um modelo fácil, intuitivo e 
acessível aos alunos
</p>
